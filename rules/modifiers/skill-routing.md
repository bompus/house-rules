## Skill selection

At the start of each task, before other work:

- Check what the user is doing and what task is in front of you.
- Of the skills available, pick the one that best solves the problem at hand, and use it.
- When the user starts the next task or changes the goal, pick again.
- Follow-ups and small edits on the same task keep the same skill.
- If none fits, do not mention it; keep working.
