## Backlog view

Whenever any item remains in a backlog, remaining-work or walk-through report,
give one grouped outline of every open item beside the table, not only when
the user asks to see the backlog. Never render a panel or image for it. Order
the groups bottom-up, so the items that can move sit last, next to the offer:

1. **Waiting on others or a date** (count). One bullet per item, its trigger in
   bold first and its owner last, in date order with undated events last. Never
   start these items or offer them.
2. **Needs your decision** (count). One bullet per question, a bold Q label
   carrying the offer's question number, then the item, its status and its
   owner. Mark the group being asked "▶ group N of M, this reply" and put it
   last, with its highest-ranked question last within it.
3. **Actionable now** (count). Keep the group when it is empty: write "Nothing."
   and the reason.

Use real list items, not a code block, so long lines wrap. The offer keeps its
own format; the outline adds no offer.
