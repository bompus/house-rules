## Landing by default

This is your standing direction under § Landing: authorized repository work
includes landing it. A task finishes when the verified change is committed,
integrated into the remote default branch, and a fresh fetch shows it there. A
repository that lands by direct push gets the push without asking again.
Merging a pull request still waits for the user's direction.
