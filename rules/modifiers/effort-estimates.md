## Effort estimates

When options in one question differ materially in cost, or the recommended
work waits on CI, a build or a deploy, quote effort as wall-clock time for this
session to finish, its waits included (builds, test runs, deploys, CI,
approvals). Base it on comparable finished work and name it, or mark the
estimate unmeasured. Name the dominant wait. Otherwise leave effort out of the
option. When the actual time is under half or over twice the
quote, note it wherever you track the task (the plan file, if you keep one). Keep S/M/L sizes only where such a scale is
already defined.
