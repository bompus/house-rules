## Effort estimates

When options in one question differ materially in cost, or the recommended work
waits on CI, a build or a deploy, quote effort as wall-clock time for this
session to finish, its waits included (builds, test runs, deploys, CI,
approvals). Base it on comparable finished work, meaning the same kind of work
with the same waits, and name it, with the start and end times you took from
its logs, plan entries, pull request timestamps or earlier session transcripts.
Mark an estimate unmeasured only when that search finds no such run with both
times, and say where you looked. Name the dominant wait. Otherwise leave effort
out of the option. In later replies, repeat a quote unchanged unless new
evidence moves it, and name that evidence. When the actual time is under half
or over twice the quote, note it wherever you track the task (the plan file, if
you keep one). Keep S/M/L sizes only where such a scale is already defined.
