## JavaScript and TypeScript runtime

Run JavaScript and TypeScript with Bun by default, including existing scripts, package
tasks and validation. Use Node only when the user explicitly requests it or a concrete
technical requirement needs it, and record that evidence before running Node. Before
choosing or changing a runtime for a command, read
[the runtime procedure](../references/bun-runtime.md).
