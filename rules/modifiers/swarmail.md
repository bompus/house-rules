## Swarmail coordination

When Swarmail is connected, read its server instructions and tool contracts
before using it. If those instructions are unavailable or omit a needed detail,
read `swarmail --help` and `README.md` in its owning checkout at the installed
or host-approved revision. If available sources do not establish that detail,
report it as unverified rather than guessing the product's operations.
