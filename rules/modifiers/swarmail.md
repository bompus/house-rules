## Swarmail coordination

When Swarmail is connected, read its server instructions and tool contracts
before using it. If those instructions are unavailable, read `swarmail --help`
and `README.md` in its owning checkout at the installed or host-approved
revision. If neither source is reachable, report coordination guidance as
unverified rather than guessing the product's operations.
