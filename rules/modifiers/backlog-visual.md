## Backlog view

Whenever any item remains in a backlog, remaining-work or walk-through report,
show one panel of every open item beside the table, grouped by what each waits
on and ordered bottom-up so the items that can move sit last. Read
[the backlog view format](../references/backlog-view.md) before building it.
Render it with the host's own preview or rendering tool; where the host has
none, give the same groups as a Markdown outline. The offer keeps its own
format; the view adds no offer.
