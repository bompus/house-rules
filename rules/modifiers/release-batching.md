## Release batching

Landing does not authorize publishing. Follow the repository's release requirements.
Before preparing or publishing a release or public announcement, read
[the release procedure](../references/release-batching.md), including its factual
accuracy audit. Run that audit on every public repository's version bump, before
the first publish step, and land its corrections first. Do not publish with
unresolved accuracy blockers or expand scope to new benchmarks.
