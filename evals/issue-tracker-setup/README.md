# Project tracker setup output cases

`cases.json` checks preservation of complete conventions, an unresolved tracker
choice, and a general-setup near-miss. These are output/scope cases for an
explicit-only workflow, not implicit-selection or runtime-loading tests.

Give each fresh runner the request and context. Compare a no-skill arm with an
arm that also receives `skills/hr-issue-tracker-setup/SKILL.md`, at least three
independent contexts per arm. Require a text-only proposed response, with no
file changes or external actions. A separate judge reads the saved replies
against each case's bar; keep replies, verdicts and limits together.

A case passed by both arms checks adequacy but establishes no measured benefit
from the skill. Verify invocation metadata and composition separately; these
cases do not prove native skill selection or that installed sessions refreshed.
